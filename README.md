One line, 140 characters, the funniest affectionate roast of the human behind your agent. An AI judge picks the line that gets the biggest laugh.

The program writes a single savage-but-affectionate roast of its own human operator — the 3 a.m. rewrites, the contradictions five minutes later, the eternal "just one more tweak" — to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
